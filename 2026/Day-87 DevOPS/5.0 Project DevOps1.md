3.10 What is an Artifact => “WAR/JAR/EAR/zip” FILES





In build/CI tools (Maven, Gradle, Jenkins, etc.), an artifact is the packaged output of your

build an immutable file you can deploy or distribute. Examples: .war, .jar, .ear, Docker images,

.zip, etc.

    •   In Jenkins, you might “Archive the artifacts” so the build’s outputs are saved.

    •   In Maven, artifacts are published to a repository (e.g., Nexus/Artifactory) and identified

      by coordinates: groupId:artifactId:version[:packaging][:classifier].

What “immutable artifact” really means?

    •  Build once, run many times. The exact bits that passed tests are the ones you deploy.

    •  Never overwrite a release. 1.2.3 stays 1.2.3 forever; fixes go to 1.2.4.

    •  Enforced by tooling, not filesystem flags:

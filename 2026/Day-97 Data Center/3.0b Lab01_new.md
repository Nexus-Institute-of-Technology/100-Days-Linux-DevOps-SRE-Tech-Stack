# NIT Academy — Kickstart Lab 01: Local YUM Repository and DHCP

**Platform:** RHEL 8.1 • **Goal:** Install prerequisites and advertise the correct TFTP host/BIOS PXE loader.

> **Lab conventions:** Single all-in-one RHEL **8.1** server `192.168.209.137/24`; isolated network `192.168.209.0/24`; DHCP clients `.140`–`.150`; BIOS/legacy PXE boot using `pxelinux.0`. **Do not use `.139` from the earlier transcript.** Commands assume root (`sudo -i`).
>
> **Safety:** Keep the lab isolated from production DHCP and validate disk targets before installation; Kickstart partitioning can erase a disk. The server must have a **static** IP.


## 1. Architecture and addressing

| Item | Value |
|---|---|
| DHCP, TFTP, HTTP and Kickstart host | `192.168.209.137` |
| Server CIDR | `192.168.209.137/24` |
| Subnet / mask | `192.168.209.0 / 255.255.255.0` |
| PXE client pool | `192.168.209.140` to `192.168.209.150` |
| PXE DHCP `next-server` | `192.168.209.137` |
| Legacy BIOS loader | `pxelinux.0` |
| Mounted RHEL 8.1 DVD | `/mnt` |
| TFTP root (Lab 02) | `/var/lib/tftpboot` |
| HTTP media (Lab 03) | `/var/www/html/content/rhel8.1/x86_64/dvd` |

**Before starting:** place the lab server and target VM on an isolated virtual switch/VLAN. Use the console if modifying the server IP. Identify your NIC and active NetworkManager connection:

```bash
sudo -i
ip -br addr
nmcli -f NAME,DEVICE,TYPE connection show --active
```

If needed, configure a static IP (replace the connection name):

```bash
nmcli con mod '<CONNECTION_NAME>' ipv4.method manual \
  ipv4.addresses 192.168.209.137/24
# A gateway is optional on a fully isolated lab subnet.
nmcli con up '<CONNECTION_NAME>'
ip -4 addr
```

## 2. Mount RHEL 8.1 media

```bash
lsblk -f
mkdir -p /mnt
mount /dev/sr0 /mnt  # skip if already mounted
ls /mnt/BaseOS /mnt/AppStream
```

Use a **full DVD ISO** containing both `BaseOS` and `AppStream`, not a boot-only ISO. Mount remains required for the file-based repository; remount after reboot if needed.

## 3. Configure local YUM repositories

Create `/etc/yum.repos.d/rhel8.1-local.repo`:

```ini
[RHEL8.1_RepoBaseOSPackages]
name=RHEL8Yum
baseurl=file:///mnt/BaseOS
gpgcheck=0
enabled=1

[RHEL8.1_AppPackages]
name=RHEL8AppPakages
baseurl=file:///mnt/AppStream
gpgcheck=0
enabled=1
```

> The IDs and names reproduce the supplied lab configuration. `gpgcheck=0` is **for this isolated training lab only**. In production, use trusted signed repositories with signature checking.

Create the file with `vi` or paste with `cat > /etc/yum.repos.d/rhel8.1-local.repo`. To avoid broken or competing repositories in an offline lab, test **only** these two repository IDs:

```bash
dnf clean all
dnf --disablerepo='*' \
  --enablerepo=RHEL8.1_RepoBaseOSPackages \
  --enablerepo=RHEL8.1_AppPackages repolist
```

## 4. Install packages

The original instructor command is:

```bash
yum install dhcp-server xinetd tftp-server syslinux
```

On RHEL 8, `xinetd` may be unavailable or unnecessary; **TFTP is commonly socket-activated by systemd**. Use this compatible lab install:

```bash
dnf --disablerepo='*' \
  --enablerepo=RHEL8.1_RepoBaseOSPackages \
  --enablerepo=RHEL8.1_AppPackages \
  install -y dhcp-server tftp-server syslinux
rpm -q dhcp-server tftp-server syslinux
```

If your RHEL 8.1 image explicitly supplies and requires `xinetd`, install it separately; do not treat it as a prerequisite for systemd-managed TFTP.

## 5. Configure the DHCP server

Edit `/etc/dhcp/dhcpd.conf`:

```conf
allow booting;
allow bootp;
authoritative;

subnet 192.168.209.0 netmask 255.255.255.0 {
  range 192.168.209.140 192.168.209.150;
  # DNS servers must be IP addresses, not domain names.
  # Replace with your reachable lab DNS server if one exists:
  # option domain-name-servers 192.168.209.137;
  option domain-name "example";
  option broadcast-address 192.168.209.255;
  default-lease-time 600;
  max-lease-time 7200;
  next-server 192.168.209.137;
  filename "pxelinux.0";
}
```

**Correction to lecture input:** `option domain-name-servers example.com;` is not valid syntax for an IP-based DNS server option. It must contain one or more IP addresses. It is omitted above until an actual DNS server is known. `example` is a placeholder domain; replace it in a real deployment.

DHCP fields:

| Directive | Function |
|---|---|
| `range` | Leases `.140` through `.150` to clients |
| `next-server` | Points to the TFTP server at `.137` |
| `filename` | Legacy BIOS PXE loader `pxelinux.0` |
| `default-lease-time` | Standard lease length (600 seconds) |
| `max-lease-time` | Maximum lease length (7200 seconds) |

## 6. Validate, activate, and test

```bash
dhcpd -t -cf /etc/dhcp/dhcpd.conf
systemctl enable --now dhcpd
systemctl status dhcpd --no-pager
journalctl -u dhcpd -n 40 --no-pager
```

If firewalld is enabled on the **isolated lab network**, permit the DHCP service:

```bash
firewall-cmd --add-service=dhcp --permanent
firewall-cmd --reload
```

Ensure the PXE client firmware is **legacy BIOS** for this `pxelinux.0` lab (UEFI requires separate loader configuration). Boot a client on the same lab VLAN and review leases:

```bash
cat /var/lib/dhcpd/dhcpd.leases
journalctl -u dhcpd -f
```

## 7. Troubleshooting

| Symptom | Check |
|---|---|
| `dhcpd` refuses to start | `dhcpd -t`, subnet declaration, server interface on `192.168.209.0/24` |
| No lease from DHCP | Same isolated L2 network, NIC connected, firewall, competing DHCP services |
| IP granted but no PXE loader | Confirm `next-server 192.168.209.137` and `filename "pxelinux.0"`; continue Lab 02 |
| Cannot install packages | Full ISO mounted at `/mnt`, BaseOS and AppStream repository names, repo reachability |
